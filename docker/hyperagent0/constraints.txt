# Pip constraints for the docker build.
#
# Constraints differ from requirements: they pin a version only IF the package
# is installed, but never install it themselves. This lets us tell pip's
# resolver "if you decide you need torch, use this exact CPU build" without
# adding torch as a direct dep (it's already pulled by openai-whisper, etc).
#
# Why each entry:
#
#   torch / torchvision  -> Lock to CPU wheels. Without these, pip backtracks
#                           into torch 2.12 which pulls ~5GB of CUDA wheels.
#                           The +cpu local version specifier only exists on
#                           https://download.pytorch.org/whl/cpu (extra-index).
#
#   scikit-learn         -> Pin minimum to prevent pip from backtracking into
#                           sklearn 1.2.x source builds that fail on Python
#                           3.12 (pkgutil.ImpImporter removed).
torch==2.7.1+cpu
torchvision==0.22.1+cpu
scikit-learn>=1.5
